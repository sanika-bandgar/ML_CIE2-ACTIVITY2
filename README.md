Machine Learning – CIE II Activity 2
 House Price Prediction Using Linear Regression

 Student Details
- Name: Sanika Ganesh Bandgar
- Course: B.Tech Artificial Intelligence and Data Science
- Subject: Machine Learning

 Aim
To build a simple Linear Regression model to predict house prices based on house area.

Dataset
- Feature: Area (sq.ft.)
- Target: Price (Lakhs)

 Libraries Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

 Procedure
1. Import required libraries.
2. Create or load the house price dataset.
3. Separate independent and dependent variables.
4. Split data into training and testing sets.
5. Create a Linear Regression model.
6. Train the model using training data.
7. Predict house prices using test data.
8. Evaluate the model using MSE and R2 score.
9. Visualize actual prices and the regression line.
10. Predict the price of a new house.

Output
- Actual and predicted prices
- Mean Squared Error
- R2 Score
- House price prediction
- Regression graph

 Conclusion
Linear Regression was used to predict house prices based on area. The model was evaluated using MSE and R2 score and visualized using a regression graph.
